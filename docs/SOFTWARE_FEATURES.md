# Software Features

The following are the major features of Firewall Duty: 3D Cybersecurity Simulation.

## 1. Account and Profile System
- User Registration
- Login Authentication
- Google Sign-In
- Forgot Password

## 2. Main Menu System
- New Game
- Continue
- Trivia Challenge
- Rankings
- Profile (Username, Player Level, EXP, Online Rank, Achievement Certificates)
- Settings
- Log Out

## 3. Trivia Challenge System
- 30 Randomized Questions
- Multiple Choice Format
- 5 EXP per Correct Answer
- Instant Score Display

## 4. Continue Game System
- Resume unfinished missions
- Access saved progress

## 5. Settings Module
- Graphics Settings
- Look Sensitivity
- Master Volume
- Sound Effects Volume

## 6. Environment Selection System
- Office Environment: 10 cybersecurity investigation missions
- Bank Environment: 10 cybersecurity investigation missions

## 7. Storyline System
- Player Background Story
- Mission Preparation Narrative
- Arrival Sequence

## 8. Mission Briefing Module
- Threat Type Briefing
- Mission Objectives
- Mission Timer Information

## 9. 3D Environment Gameplay System
- Free Movement System (Floating Virtual Joystick)
- Touch Look Controls
- Interactive Environment (Doors, Seats, Computers)
- Floor Arrow Guide
- Footstep and Environment Sounds

## 10. NPC Interaction System
- NPC Types: Manager, Receptionist, IT Security Team, Office Employees, Bank Tellers, Bank Customers
- Features: Dialogue System, Receiving Clues, Interviewing Suspects, Reporting Suspicious Activities

## 11. Cyber Tablet System
- Features: Threat Indicators, Threat Examples, Investigation Notes, Threat Encyclopedia
- Threat Categories:
  1. Phishing Emails
  2. Malware Files
  3. Spam Mail
  4. Fake Pop-up Warnings
  5. Social Engineering Attempts
  6. Unauthorized Access Attempts

## 12. Threat Detection System
Each mission uses a different detection method, and the evidence is always the three indicators listed on the Cyber Tablet.
- Email and Document Analysis
- Evidence Board and Chat Analysis
- Place Inspection
- Interview
- Live Login Monitor
- Spam Filter Control
- Email Comparison

## 13. Threat Analysis and Decision-Making System
- Evidence Inspection
- Sender Verification
- Threat Identification
- Response Selection
- Instant Green and Red Answer Feedback

## 14. Mission Timer System
- Countdown Timer per Mission
- Time Penalty for Mistakes
- Timeout Ends the Mission

## 15. Reward and Penalty System
- Correct Actions: Gain EXP, Earn Points, Level Up, Unlock Missions, Unlock Achievements
- Wrong Actions: Lose EXP and Points, Lose Time
- EXP and points are awarded only on the first finish of a mission.

## 16. Mission Outcome Report System
- Mission Title
- Environment and Threat Type
- Time Remaining
- EXP Gained
- Objective Checklist
- Return to Operations Hub
- Restart Mission

## 17. Leaderboard and Progression System
- Rank, Player, and Level
- Player's Own Rank
- Level-Up System
- Unlock New Missions

## 18. Achievement Certificate System
- Phishing Detection Certificate
- Malware Detection Certificate
- Pop-Up Protection Certificate
- Spam Mail Analyst Certificate
- Social Engineering Awareness Certificate
- Access Control Defender Certificate
- Trivia Master Certificate

## 19. Auto-Save System
- Auto-Save Functionality
- Saved Mission Progress
- Saved Unlocked Content

## 20. Operations Hub System
- Mission Selection
- Player Progress Monitoring
- Cyber Tablet Access

## 21. Pause Menu System
- Resume Game
- Settings Access
- Quit to Main Menu
